# 🌍 Voking Online

Многопользовательский онлайн-мир в реальном времени — **основа MMO**.
У каждого игрока свой персонаж; вы видите друг друга, двигаетесь по общему миру и общаетесь в чате.

Написано на чистом **Node.js + WebSocket** (сервер) и **HTML5 Canvas** (клиент), без фреймворков.

## Как запустить

```bash
npm install      # один раз — установит зависимость ws
npm start        # запустит сервер
```

Затем открой в браузере **http://localhost:3000**

Чтобы поиграть вдвоём/втроём — открой эту ссылку в нескольких вкладках,
или на других устройствах в той же сети по адресу `http://<твой-IP>:3000`.

При первом заходе открой **http://localhost:3000** — тебя перебросит на страницу
входа `/login.html`. Зарегистрируйся (имя 3–16 символов, пароль от 6 символов) и
попадёшь в мир уже под своим аккаунтом.

## Управление

- **WASD** или **стрелки** — движение
- **Enter** — написать в чат
- Кнопка **«Выйти»** в левом верхнем углу — выход из аккаунта

## Аккаунты и безопасность

- Регистрация и вход: `POST /api/register`, `POST /api/login`
- Пароли хранятся как **соль + scrypt-хеш** (встроенный `crypto`), не в открытом виде
- После входа выдаётся **токен сессии**; вход в мир по WebSocket проверяет токен,
  поэтому подделать чужое имя нельзя
- Пользователи сохраняются в `data/users.json` (папка `data/` в `.gitignore`)

## Что уже есть

- Общий мир 2000×2000 с камерой, следующей за игроком
- Свой персонаж (цвет и имя), видно всех онлайн-игроков в реальном времени
- Синхронизация позиций ~20 раз в секунду
- Чат и системные сообщения (кто зашёл / вышел)
- Счётчик игроков онлайн

## Структура

| Файл | Назначение |
|------|------------|
| `server.js` | Игровой сервер: общий мир, WebSocket, рассылка состояния, API аутентификации |
| `auth.js` | Регистрация, вход, хеширование паролей, токены сессий |
| `public/login.html` | Страница входа и регистрации |
| `public/index.html` | Клиент игры: рендер мира, персонаж, движение, чат |
| `public/memory.html` | Бонус: одиночная игра «Память» |
