# 🌍 Voking Online

Многопользовательский онлайн-мир в реальном времени — **основа MMO**.
У каждого игрока свой персонаж; вы видите друг друга, двигаетесь по общему миру и общаетесь в чате.

Написано на чистом **Node.js + WebSocket** (сервер) и **HTML5 Canvas** (клиент), без фреймворков.

## Как запустить

```bash
npm install      # один раз — установит зависимость ws
npm start        # запустит сервер
```

Затем открой в браузере **http://localhost:3000**

Чтобы поиграть вдвоём/втроём — открой эту ссылку в нескольких вкладках,
или на других устройствах в той же сети по адресу `http://<твой-IP>:3000`.

При первом заходе открой **http://localhost:3000** — тебя перебросит на страницу
входа `/login.html`. Зарегистрируйся, затем на экране **выбора персонажа** создай
выжившего (только имя) и зайди в мир.

## Админка (`/admin.html`)

Первый зарегистрированный аккаунт автоматически становится **администратором**
(или укажи логины в переменной `ADMIN_USERS=имя1,имя2`). У админа на экране
персонажей появляется ссылка «🛠️ Админка», где можно:

- **Загружать спрайт выжившего** — один общий PNG персонажа; заменяет
  рисованную фигурку у всех игроков
- **Менять текстуру земли** — два цвета тайлов
- **Добавлять объекты на карту** — загрузить спрайт (дерево, камень…) и кликом
  по мини-карте расставить его, с масштабом

Все изменения **сразу видят игроки в онлайне** (рассылаются по WebSocket).
Загруженные картинки лежат в `public/sprites/` (папка в `.gitignore`).

## Аккаунты и персонажи

- **Аккаунт** — логин и пароль (страница `/login.html`)
- **Персонажи (выжившие)** — на экране `/characters.html`: до 6 персонажей на
  аккаунт, у каждого своё имя, цвет и сохранённые позиция и статы выживания
- Позиция и статы **сохраняются между входами** — мир персистентный

## День и ночь

В мире идёт общее **игровое время** (ведёт сервер, одинаковое для всех):

- В HUD рядом с ником — часы и фаза: `☀️ 14:30 · День` / `🌙 23:10 · Ночь`
- Ночью мир **затемняется** (плавно темнеет к полуночи и светлеет к полудню)
- Полные сутки по умолчанию длятся 10 минут; настраивается: `DAY_LENGTH_SEC=120 npm start`

## Погода (общая для всех)

Погода **разыгрывается раз в сутки в полдень (12:00)** независимыми бросками
(повтор возможен — может выпасть гроза два дня подряд):

- ☠️ **Споры** — 1 к 20
- 🔥 **Жара** — 1 к 15
- 🌧️ **Гроза** — 1 к 10
- ☀️ иначе **Ясно**

Броски проверяются от самого редкого к частому, погода держится до следующего
полудня. Эффекты:

- ☀️ **Ясно** — без эффектов
- 🔥 **Жара** — жажда 💧 убывает гораздо быстрее (пейте больше, иначе обезвоживание)
- 🌧️ **Гроза** — дождь и молнии; есть шанс **простудиться** (болезнь какое-то время
  отнимает здоровье, в HUD горит 🤢)
- ☠️ **Ядовитые споры** — глобальный ивент: сначала предупреждение с отсчётом, затем
  волна. Вне **убежища** — смертельный урон. По карте расставлены безопасные зоны
  (⛺, в т.ч. стартовая в центре) — нужно успеть добежать и переждать волну.

Текущая погода и фаза показаны в HUD рядом с часами; во время спор сверху висит баннер.

Для тестов/баланса: `FORCE_WEATHER=heat|rain|spores`, `SPORE_WARNING_SEC`, `SPORE_DURATION_SEC`.

## Ночные угрозы — орды зомби

Ночью мир становится опасным:

- С наступлением ночи сервер **спавнит орду зомби** рядом с игроками (размер орды
  растёт с числом игроков); в чат приходит предупреждение
- Зомби идут к **ближайшему игроку** и кусают его (урон по здоровью); экран
  вспыхивает красным при укусе, над зомби видна полоска здоровья
- Зомби **медленнее** игрока — от них можно убегать и кайтить
- **Атака по пробелу** — бьёшь зомби в ближнем радиусе (≈3 удара на зомби)
- На **рассвете** орда исчезает

Для теста: `FORCE_NIGHT=1 npm start` — вечная ночь (постоянный спавн орды).

## Выживание

Онлайн-выживание: у каждого персонажа есть статы, которые ведёт **сервер**:

- ❤️ **Здоровье**, 🍖 **Голод**, 💧 **Жажда**, ⚡ **Энергия** (0–100), показаны шкалами внизу экрана
- Голод, жажда и энергия убывают со временем (энергия быстрее при движении, жажда быстрее в жару)
- Если голод, жажда или энергия на нуле — **падает здоровье**; при сытости/бодрости/утолённой жажде здоровье регенерирует
- При нуле здоровья — **смерть и возрождение** в центре мира
- Статы и позиция **сохраняются** у персонажа между входами
- Полоска здоровья видна над ранеными игроками

Скорость убывания можно ускорить для теста/балансировки: `SURVIVAL_SPEED=50 npm start`.

> Пока нет еды — статы только убывают (следующий шаг: добыча ресурсов и еда,
> чтобы восполнять голод).

## Стиль

Игра рисуется в **изометрии (2.5D)** — объёмный вид под углом, как в классических
RPG (Diablo, Ultima Online). Мир строится из ромбовидных тайлов на HTML5 Canvas,
персонажи сортируются по глубине. Без 3D-моделей.

## Управление

- **WASD** или **стрелки** — движение (ориентировано по экрану)
- **Пробел** — атака (по зомби в ближнем радиусе)
- **Enter** — написать в чат
- Кнопка **«Выйти»** в левом верхнем углу — назад к выбору персонажа

## Аккаунты и безопасность

- Регистрация и вход: `POST /api/register`, `POST /api/login`
- Пароли хранятся как **соль + scrypt-хеш** (встроенный `crypto`), не в открытом виде
- После входа выдаётся **токен сессии**; вход в мир по WebSocket проверяет токен,
  поэтому подделать чужое имя нельзя
- Пользователи сохраняются в `data/users.json` (папка `data/` в `.gitignore`)

## Что уже есть

- Общий мир 2000×2000 с камерой, следующей за игроком
- Свой персонаж (цвет и имя), видно всех онлайн-игроков в реальном времени
- Синхронизация позиций ~20 раз в секунду
- Чат и системные сообщения (кто зашёл / вышел)
- Счётчик игроков онлайн

## Структура

| Файл | Назначение |
|------|------------|
| `server.js` | Игровой сервер: общий мир, WebSocket, рассылка состояния, API аутентификации |
| `auth.js` | Регистрация, вход, хеширование паролей, токены сессий, роль админа |
| `characters.js` | Персонажи: создание, удаление, сохранение позиции и статов |
| `world.js` | Состояние мира: земля, объекты, загрузка спрайтов |
| `public/login.html` | Страница входа и регистрации |
| `public/characters.html` | Экран выбора и создания персонажей |
| `public/admin.html` | Админка: спрайты, земля, объекты на карте |
| `public/index.html` | Клиент игры: рендер мира, персонаж, движение, чат |
| `public/memory.html` | Бонус: одиночная игра «Память» |
